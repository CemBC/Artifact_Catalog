# Artifact Catalog

A Java desktop application for storing, organizing, and searching artifact records.

## Features

- Artifact data model
- Catalog management
- Search functionality
- Dimension records
- File-based persistence
- Graphical user interface
- Separation of catalog, search, file, and UI responsibilities

## Technologies

- Java
- JavaFX
- Maven
- Object-oriented design
- File management

## Running the Project

```bash
mvn clean javafx:run
```

A compatible Java Development Kit and JavaFX environment are required.
